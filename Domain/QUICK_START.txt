        new AgentSystemPrompt("You are an expert..."),

    if (agent.IsValid)
        await _agentRepository.AddAsync(agent);

Aggregate Root
  • Raiz agregada - entry point do agregado
  • Encapsula invariantes de negócio
  • Gera eventos de domínio
  • Factory method estático Create()

Value Object (VO)
  • Imutável
  • Sem identidade (comparado por valor)
  • Validado no constructor
  • Sealed class

Domain Event
  • Fato do passado (record)
  • Imutável com timestamp
  • Gerado pelo agregado
  • Publicado após persistência

Specification
  • Encapsula critério de query
  • Reutilizável em repositórios
  • Sem SQL espalhado
  • Suporta paging, includes, order by
